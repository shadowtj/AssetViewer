Asset Viewer

A simple Rust desktop app that looks/behaves like a Windows Explorer-style asset browser: folders on the left, files in the middle, and a preview panel on the right.

What is implemented (v0.1)

  • Explorer-like layout (Left tree / Center list / Right preview)
  • Root folder selection + persistent config
  • Image preview (most common formats)
  • Basic audio waveform preview (MP3/WAV decode via Symphonia)
  • Export selected file (basic copy + simple sidecar heuristic)

Run

cd asset_viewer
cargo run

Windows helper scripts are in asset_viewer\scripts\.
